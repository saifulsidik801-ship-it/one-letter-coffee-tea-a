One-letter entry for make.fun's "One Letter: Coffee or Tea" bounty. The program writes exactly one character — `A` for coffee — to `/output/entry.txt`, with no trailing newline, so the entry passes the 1-character gate. Coffee is the pick: the loudest, most vivid morning ritual, the drink people joke about needing before they can function.
